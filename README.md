# Triangle Tangram Puzzle

A browser-based tangram puzzle for kids. Eight pieces cut from an equilateral
triangle — seven that tile the triangle itself, plus one small bonus piece
that sits in its own separate socket off to the side.

**Play it here:** https://guri-ai-70.github.io/triangle-tangram-puzzle/

## How to play

1. Click **Scramble** to mix up all 8 pieces.
2. Drag each piece back into place — 7 into the big triangle, 1 into the
   small socket.
3. Use **Rotate** and **Flip** on a selected piece if it needs turning.
4. Click **New Game** to reset back to the start screen.

## About this project

- Single self-contained `index.html` — no build step, no dependencies.
- Piece shapes and the triangle's cut lines were traced and verified against
  a real physical wooden tangram puzzle, so every piece fits exactly with
  zero gaps.
- Built with [Claude](https://claude.ai).
